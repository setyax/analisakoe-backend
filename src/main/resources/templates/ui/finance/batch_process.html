[F0708] Batch Process Jurnal

✅ Batch POST

Ubah transaksi berstatus CONFIRMED menjadi POSTED dan buat jurnal otomatis.

↩️ Batch UNPOST (Cancel Jurnal + Revert Status)

Ubah transaksi berstatus POSTED kembali menjadi CONFIRMED dan hapus jurnal otomatisnya.

🗑️ Hapus Jurnal Auto (Khusus Jurnal)

Hanya menghapus jurnal otomatis tanpa mengubah status dokumen SI/PI.
